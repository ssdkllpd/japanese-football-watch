## 検証とレビュー資料

外部通信を遮断した `node --test tests/*.test.js` は673件中671 pass / 0 fail / 2既存TODO（実時計2026-10-06）でした。29件のworkflow YAML、155個のbashブロック、変更した30個のJavaScriptの構文と差分の空白検査も成功しました。ローカルは Node 24.19.0。Node 22のCIに同じスイートと、固定したwrangler 4.147.0のローカルworkerd検証を追加しました。

追加の回帰テストは、提供されたn1〜n6の29ケースを修正後のAPIと監査入力に合わせたものです。主な適応は、日付単位修復を複数の実Admin呼出しで排出すること、監査の追加D1列と訂正値・修復キューを取得すること、freshサンプルを使うこと、大量欠落の期待値を拒否にすることです。原本を変更して独立レビューの合格と扱ってはいません。原本ZIPも再レビュー用バンドルに保持します。

SQLiteの全体スイート、実workerdのログ、実YAMLを使ったシェルテスト、全ソースのハッシュと差分を再レビュー用ZIPに同梱します。実workerd検証は日程更新、部分R2失敗、古い更新の拒否に加え、結果公開UPSERTと日付移動後のR2失敗・再試行を実行します。
