# ChatGPTへの試合分析の引き渡し

試合詳細の「ChatGPTで分析」を押すと、表示中の試合データから分析用テキストを作成し、クリップボードへのコピーとChatGPTの別タブ起動を行う。ChatGPTに貼り付けて送信し、気になる点を追記して対話を続ける。

- コピー失敗時はダイアログのテキスト欄が開き、全文を選択する。手動コピーと再コピーが可能。
- 別タブが開かない場合はダイアログ内の「ChatGPTを開く」を使う。
- 特定のチャット・プロジェクト・Workへの切り替え、送信は自動化しない。

## スナップショット

`jfw-analysis.js`が`jfw-analysis-v1`形式のJSONと分析指示を生成する。対象は試合情報、ラインナップ、イベント、チーム統計、全取得選手の統計、JFW評価の計算結果・不足項目。写真やフォロー状態は渡さない。試合URLにはページのクエリ文字列を含めない。

`capturedAt`はテキスト作成時刻、`detailReceivedAt`はブラウザが詳細を受信した時刻。元の更新時刻はレコードの`reconciledAt`と`provenance.fetchedAt`に残す。速報のスコアを反映した`displayedFixture`と詳細統計の基準である`detailFixture`を区別し、更新の遅延・保持された古いデータのフラグも残す。

数値の0は維持する。未取得・提供元欠損・非該当・不整合は`fieldStates`に区別して保存し、利用できない値は`null`とする。取得されていないセクションを「イベントなし」「出場選手なし」と解釈しないよう指示する。APIの値とJFW独自評価は分け、未算出理由も記録する。

ダイアログはライブ再描画の対象外に置き、開いている間は作成時のテキストを維持する。閉じてもう一度「ChatGPTで分析」を押すと、その時点で読み込み済みのデータから作り直す。

この操作で追加の試合取得、提供元APIへのリクエスト、DBへの保存は行わない。OpenAI APIも呼ばず、ChatGPTへの自動送信や分析結果の自動取り込みは行わない。

## 検証

`tests/jfw-analysis.test.js`で欠損・0・不整合、時点の分離、JFW未算出理由を確認する。`tests/app-v2-runtime.test.js`でコピー成功、権限拒否と非対応の手動コピー、追加取得なし、ライブ再描画中のスナップショット維持と再作成を確認する。
