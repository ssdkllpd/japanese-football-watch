# 選手ディレクトリと名簿の更新

## 保存内容

- `players` は API-Football の選手 ID を本人のキーとして、国籍・生年月日・写真を保持する。既存の試合取込でプロフィール値が欠けても、取得済みの国籍を消さない。
- `player_roster_observations` はチーム名簿・シーズン選手ページでその日に確認した所属を保持する。`observed_on` は移籍日ではない。試合当日の所属は `fixture_player_records.team_id` を使う。
- `/api/v2/players?nationality=Japan` は対象リーグの最新完了名簿に所属し、日本国籍が確認された選手を返す。`nationality=all`、取得済みの任意の国籍名、`team=af:team:<id>`、`after=<providerId>` に対応する。100人ずつ取得する。国籍名はアクセント付き文字にも対応し、未取得の国籍を推定しない。
- `includeNationalities=1` を付けると、最新完了名簿全体に存在する国籍名を `nationalities` として併せて返す。名前検索・国籍フィルター・ページ境界には依存せず、国籍未取得と名簿を離れた選手はこの選択肢に含めない。指定しなければ追加の国籍一覧照会は行わない。
- `/api/v2/players/af:player:<id>` は本人のプロフィールと名簿で確認したクラブ履歴を返す。大会の `playerStats.teamRows` は試合当時のチーム別成績であり、移籍後の所属名簿には左右されない。

## 自動更新

`.github/workflows/api-football-player-roster-sync.yml` は毎週日曜 02:17 UTC に対象10リーグの全選手ページと全クラブ名簿を読み取る。国籍が不明の名簿選手はシーズンに依存しない `/players/profiles?player=<id>` で確認し、取得できない場合は2026年・2025年の選手ID照会で国籍を補う。全10リーグの取得が完了し、選手数・チーム数・API残量・D1月間書込予算の確認が通った場合だけ、管理Workerに40人ずつ送る。API残量500件を常に確保する。このWorkflowがmainに反映されたときにも初回取込を実行する。取得した原データはR2 `audit/player-rosters/<runId>.json` に保存してから公開し、同じスナップショットから再試行できる。手動起動は `preview` と `execute`（確認文字列 `RUN PLAYER ROSTER SYNC`）を選べる。

名簿をrun_idごとに準備し、選手数・観測行数・全クラブIDを照合してから完了済みに切り替える。現在所属は最新の完了済みrunのチーム名簿だけから読む。シーズンの選手成績ページにある旧クラブを現在所属には使わない。途中で送信が失敗したrunは所属一覧に反映しない。同一runの再送は完了前のみ重複なく行え、古いrunの再投入で最新所属・プロフィールを巻き戻さない。試合結果を再取得する処理ではない。

## 従来プロフィール

現行画面のタブ名は「選手一覧」。初期表示は全国籍で、各行に国籍を表示する。国籍未取得は明記し、国籍を選ぶとサーバー側で名簿全体を絞り込む。旧 `#/japanese` URL は引き続き利用できる。配信先のUIは試合一覧・試合詳細から削除し、保存済みの `watch` 項目と視聴価値ランキングは維持する。

共通検索の「日本人所属クラブのみ」は、国籍が `Japan` の名簿選手を全ページ読み、`rosterTeams` のクラブIDから判定する。全ページ確認後に有効となり、検索語なしでも対象クラブを一覧できる。名前・過去の所属履歴・固定追跡リストからは所属を推定しない。検索結果・試合一覧・順位表・チーム成績・フォロー中のクラブ・クラブ詳細に共通の「日本人所属」印を表示し、検索結果とクラブ詳細には確認できた選手名も表示する。これは最新保存名簿の所属を示し、その試合当日の所属や出場を示すものではない。

名簿取得失敗・不正なカーソル・ページ間の名簿確認日の変化は、部分的な結果を公開せず明示的な再試行にする。未確認を日本人不在として扱わない。所属情報の到着で検索入力や遷移先を上書きしない。既存の試合「日本人」フィルターの、試合日時と追跡期間に基づく判定は変更しない。

旧64人全員の API-Football ID を `tracked-player-provider-ids.js` に明示した。確認済みの試合成績を旧日本語プロフィールにも表示し、国籍一覧では同じ人を重複させない。伊藤涼太郎は2024年STVV選手ページ、神代慶人は選手プロフィールの氏名・国籍・生年月日から本人IDを確認した。現行名簿への所属や出場成績とは独立した照合であり、名簿にない選手を現在所属一覧へ加えない。小川航基のIDは2025年のNEC選手ページで確認したが、2026年の対象10リーグ外の移籍先を追跡対象には加えない。

新規加入者は固定表へ追加せず、APIから得た選手IDと国籍で一覧へ入る。国籍未取得の名簿選手は「すべて」には表示されるが、日本人絞り込みには入らない。対象リーグから離れた選手の過去の試合記録は残る。

プロフィールには公開済みリビジョンに結び付く直近20試合を表示する。未使用ベンチや未公開リビジョンを出場試合として加算しない。

照合根拠は `config/tracked-player-provider-evidence.json` に保持する。

旧 `tracked_players` の追跡期間・独自レーティング集計の移行はこの変更では行わない。新しい選手一覧・プロフィール・クラブ名簿・試合記録はproviderの選手IDを共通キーに使い、旧日本語URLは確認済み対応表から同じプロフィールへ接続する。
