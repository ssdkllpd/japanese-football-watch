# JFW Rating v1.0 — 計算式仕様

海外日本人選手評価指標。取得できた実データのみを使い、欠損を推測しない。

## 0. 基本構造

```text
JFW = clamp( 6.00 + Δ_perf × K_cov × K_min + Δ_disc , 3.00, 10.00 )
```

- `Δ_perf`: プレー内容の加減点合計
- `Δ_disc`: 規律系の減点。縮小をかけない
- `K_cov`: データ充足率による縮小係数
- `K_min`: 出場時間による縮小係数
- 未出場（0分）は `null`
- 基礎最低算出条件は `minutes / goals / assists` がすべて `value`
- 実装整合性ガードとして、縮小対象外の規律項目もすべて `value`（0を含む）であることを要求する。欠損時は0とみなさず `null`

## 1. 入力値の3状態

| 状態 | 意味 | C分子 | C分母 |
|---|---|---:|---:|
| `value` | 取得済み。0を含む | 入る | 入る |
| `missing` | 取得不能 | 入らない | 入る |
| `notApplicable` | 母数不足で評価対象外 | 入らない | 入らない |

率系のみ `notApplicable` を使用する。母数自体を取得できない場合は `missing`。

## 2. データ充足率

```text
C = Σ(value の重み) / Σ(value と missing の重み)
K_cov = 1.30 × C / (C + 0.30)
```

信頼度は `High: C>=0.75 / Medium: C>=0.40 / Low: C<0.40`。
欠損値を平均値や0で補完しない。充足率が高いほど取得済みパフォーマンスを強く反映する。

## 3. 出場時間

```text
K_min = 1.2222 × m / (m + 20)
```

`m` は90分でクランプ。90分=1.000、70分≈0.952、45分≈0.846、20分≈0.611、10分≈0.407、5分≈0.244。

## 4. DF/GKの在場中失点

DF/GKの失点はチーム総失点ではなく `GA_onpitch` を使う。

```text
GA_onpitch = 選手がピッチ上にいた時間帯に発生した失点数
```

出場開始/終了分または各失点分を取得できない場合は `missing`。フルタイム総失点で代用しない。
同一分イベントの例外運用は `docs/jfw-rating-ops-v1.0.md` に従う。

## 6. 規律減点

- イエロー `-0.20 × yellowCards`
- 2枚目イエロー退場 `-0.70` を追加
- 一発レッド `-1.20`
- PK献上 `-0.50 × n`
- オウンゴール `-0.80 × n`

規律項目は充足率の分母に入れない。`yellowCards / secondYellowRed / straightRed / penaltiesConceded / ownGoals` はすべて明示的な `value` として保存する。0件なら `value: 0`、取得不能ならRatingを算出しない。

## 7. シーズン集計

```text
シーズン平均 = Σ(JFW_i × minutes_i) / Σ(minutes_i)
```

`K_min` とシーズン出場時間加重は意図的に二重で効かせる。50〜100試合蓄積後、先発中心・途中出場中心・若手の3群で分布を検証する。

直近値は「直近5出場」を窓にする。Rating算出不能試合を飛ばして過去へ遡らない。

内部保存は小数第2位、UI表示は小数第1位。表示値を再集計に使わない。

## 8. 保存

各 `playerMatchStats` レコードは以下を保持する。

- `jfwRating`
- `ratingVersion: "1.0"`
- `ratingPosition`
- `ratingPositionSource`
- `ratingCoverage`
- `ratingConfidence`
- `ratingFactors`
- `ratingInputs`（必ず生データと状態を保存）
- `ratingBreakdown`
- `ratingSources`
- 必要時 `ratingConflicts / revisedAt / previousRating / gaOnPitchAmbiguous`

式を変更した場合は `ratingVersion` を上げ、保存済み生入力から対象データを全再計算する。バージョン混在のシーズン平均は禁止。

## 9. v1.0でしないこと

- ポジション横断ランキング
- 対戦相手強度補正
- xG/xA依存
- 監督評価・戦術文脈の定量化

FWの7.5とDFの7.5はv1.0では同じ意味ではない。UIでもポジション内指標として扱う。
