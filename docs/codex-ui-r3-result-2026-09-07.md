## テストの見逃し原因

- シーズン変更: 従来テストでは変更先の2025シーズンが既に選択済みだった。初期値が2026であることを先に検証し、2025へ変更した後の URL / 選択値 / タブを検証する。
- スクロール: 元の座標が残っただけでも成功し得た。詳細で別の位置へ移動してから戻り、`scrollTo` の呼び出し値を検証する。遅延一覧で一度座標が制限された場合の再復元も検証する。
- popstate: URL の異なる戻りでは hashchange が代わりに処理し得る。同じ hash の別履歴エントリを実際に作り、`history.back()` により popstate だけが発生する状況を検証する。
- フィルター: 異なる試合集合を明示し、all / live / following / japanese の正確な ID 集合を比較。追跡チームが同じでも J1 大会の試合は除外する。
- CSS: jsdom でメディアクエリ内の CSSOM 契約を確認する。実レイアウト計測の代替ではない。
